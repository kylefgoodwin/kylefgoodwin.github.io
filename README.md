# kylefgoodwin.github.io

Personal portfolio website for **Kyle F. Goodwin**.

- Live site: `https://kylefgoodwin.github.io/`
- Pages: `index.html` (home) and `projects.html` (projects)

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript (inline in pages)
- GitHub Pages for hosting

## Project structure

- `index.html` Home / about / featured work
- `projects.html` Project list + filters
- `style.css` Shared styles + theme system
- `images/` Site images (profile photo, etc.)
- `docs/` Downloadable documents (resume)
